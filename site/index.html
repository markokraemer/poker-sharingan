The project

A Rust poker engine, Monte Carlo CFR training, blueprint inference and optional turn/river search. The evaluation tools use duplicate deals and AIVAT to reduce variance and report confidence intervals.

One run. Two releases.

SHARINGAN-1C@2e10 — the earlier checkpoint.
SHARINGAN-2C@1.83e11 — the full-length blueprint.

Both models use six players, 100 bb stacks and the medium bet-size menu. Search is provided by the code, separately from the weights.
