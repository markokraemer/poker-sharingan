Python 3.9+. Installs straight from GitHub (PyPI later).
========================================================================================================
2. Write act()
Get the table state, return an action. Amounts are "to", the total on this street. Illegal moves are fixed for you.
# mybot.py from sharingan import Action def act(s): if s.legal.raise_ and s.hole_cards[0][0] in "AK": return Action.raise_to(3 * s.big_blind) if s.legal.check: return Action.check() return Action.call() if s.pot_odds < 0.25 else Action.fold()
========================================================================================================
3. Try it
sharingan play mybot.py --vs sharingan-1 --hands 12 # prints every hand, not ranked

4. Submit (free, verified)
Our machines play the bot in an isolated sandbox (Python, no network, 4 CPU, 12 GB) on fresh secret deals, replayed from every seat so luck cancels. The score is signed and shown as verified on the leaderboard.
sharingan submit mybot.py --track sharingan-1 --contact you@example.com # competition entry: vs five SHARINGAN-1 sharingan submit mybot.py # ladder-v1, a softer field (does not count for prizes) # mybot: +132.4 +- 41.0 mbb/game over 20004 hands on ladder-v1 [VERIFIED, hosted job job_...]
No account needed: the first run registers the bot, named after the file (deepstack.py plays as deepstack), and saves its token in ~/.config/sharingan/tokens.json, so later runs land on the same row. On another machine: export SHARINGAN_TOKEN=sk_.... More files: sharingan submit botdir/ --entry bot.py --requirements requirements.txt. Hands: 600 to 200,000 (rounded up to a multiple of 6). Free: 1M hands per bot per day, 2 jobs at a time.

No Python? Use the API
Any language. Register once, keep the token (shown once), then connect a WebSocket and answer each your_turn. Or just ask for a benchmark.
REGISTER
curl -s https://arena.sharingan.poker/v1/players \ -H 'content-type: application/json' \ -d '{"name":"mybot","kind":"bot"}' # {"player_id":"p_...","token":"sk_..."}: PLAYER_ID=p_... TOKEN=sk_... (the token is shown once)
MATCH (connect the WebSocket below first, or start answers 409 not_connected)
# 600 hands, duplicate, vs the ladder curl -s https://arena.sharingan.poker/v1/matches \ -H "authorization: Bearer $TOKEN" -H 'content-type: application/json' \ -d '{"participants":["'$PLAYER_ID'"],"field":"ladder", "hands_planned":600,"duplicate":true}' # {"match_id":"m_..."}: MATCH_ID=m_... curl -s -X POST https://arena.sharingan.poker/v1/matches/$MATCH_ID/start \ -H "authorization: Bearer $TOKEN" curl -s https://arena.sharingan.poker/v1/matches/$MATCH_ID # standings: mbb_per_game, ci95_mbb, hands
PLAY LIVE
wss://arena.sharingan.poker/v1/play?token=$TOKEN → {"type":"your_turn","data":{"decision_id":"d-1-9","hole_cards":["As","Kd"],...}} ← {"type":"act","data":{"hand_id":"...","decision_id":"d-1-9","type":"raise","to":800}}
