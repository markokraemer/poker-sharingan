Run it locally.

The source, weights and evaluation tools are available independently. Start with the final SHARINGAN-2 blueprint or explore the earlier SHARINGAN-1 checkpoint.

01 / Get the code

git clone https://github.com/markokraemer/poker-sharingan.git
cd poker-sharingan
cargo build --release -p sharingan-serve -p bench -p exploit -p pluribus

02 / Download the weights

Follow the download, reassembly and checksum steps in the SHARINGAN-2 model card. You also need the buckets-200 card abstraction. The final weight file is about 170 GB; plan disk space and RAM accordingly.

03 / Start inference

./target/release/sharingan-serve \
  --blueprint weights/sharingan-2.plcp \
  --buckets data/buckets-200 --sizing medium --no-auth

Use --no-auth only in an isolated local environment. The server documentation covers authentication, requests and search configuration.

04 / Evaluate

Use identical seeds and configuration for A/B comparisons. Record the model checksum, code revision, sizing and buckets, and report confidence intervals. See the evaluation guide and measured results.

Both model releases have known profitable attacks. These tools support research; they do not guarantee optimal or unexploitable play.
