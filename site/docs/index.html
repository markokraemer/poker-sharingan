========================================================================================================
Three steps. Your bot plays the house ladder and gets a luck-corrected score.
========================================================================================================
1. Install
pip install sharingan
========================================================================================================
2. Write act()
Get the table state, return an action. Amounts are "to", the total on this street. Illegal moves are fixed for you.
# mybot.py from sharingan import Action def act(s): if s.legal.raise_ and s.hole_cards[0][0] in "AK": return Action.raise_to(3 * s.big_blind) if s.legal.check: return Action.check() return Action.call() if s.pot_odds < 0.25 else Action.fold()
========================================================================================================
3. Run eval
sharingan eval mybot.py
A duplicate match against the ladder: every deal is replayed from every seat, so luck cancels. One line comes back.
mybot: +132.4 ± 41.0 mbb/game (95% CI) over 3000 hands vs ladder [duplicate]
========================================================================================================
No Python? Use the API
Any language. Register once, keep the token (shown once), then connect a WebSocket and answer each your_turn. Or just ask for a benchmark.
REGISTER
curl -s https://arena.sharingan.poker/v1/players \ -H 'content-type: application/json' \ -d '{"name":"mybot","kind":"bot"}' # {"player_id":"p_...","token":"sk_..."}
BENCHMARK
# 600 hands, duplicate, vs the ladder curl -s https://arena.sharingan.poker/v1/matches \ -H "authorization: Bearer $TOKEN" -H 'content-type: application/json' \ -d '{"participants":["'$PLAYER_ID'"],"field":"ladder", "hands_planned":600,"duplicate":true}' # {"match_id":"m_..."} curl -s -X POST https://arena.sharingan.poker/v1/matches/$MATCH_ID/start \ -H "authorization: Bearer $TOKEN" curl -s https://arena.sharingan.poker/v1/matches/$MATCH_ID # standings: mbb_per_game, ci95_mbb, hands
PLAY LIVE
wss://arena.sharingan.poker/v1/play?token=$TOKEN → {"type":"your_turn","data":{"decision_id":"d-1-9","hole_cards":["As","Kd"],...}} ← {"type":"act","data":{"hand_id":"...","decision_id":"d-1-9","type":"raise","to":800}}
